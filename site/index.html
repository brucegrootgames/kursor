The Cursor experience,
on your own Claude Code.

Kursor is an open-source, Cursor-style AI editor built on VS Code (VSCodium). Agent chat, Ctrl+K inline edits and Tab completions, all powered by the Claude Code CLI already installed and signed in on your machine. No new account, no API keys, no middleman.

Everything you reach for in Cursor

The same muscle memory, the same panes, the same review flow. Kursor's extension reimplements the Cursor UI on top of the Claude Code agent loop.

Agent chat

Agent, Ask and Plan modes in the secondary side bar. Streaming replies, tool rows for Read / Search / Run / Edit, @-mentions for files, folders, problems, terminal and git, slash commands, image attachments.

Ctrl+I toggle · Ctrl+L add selection

Review every edit

Agent edits land in your files with Keep / Undo / Review per file and per hunk, a review bar for the whole turn, and checkpoints to restore files to the state before any message.

Ctrl+Enter keep all · Ctrl+⇧+⌫ undo all

Ctrl+K inline edit

Describe a change over a selection; Kursor shows a red/green diff in place with Accept / Reject per block. Quick question, whole-file edit and send-to-chat from the same prompt.

Ctrl+K · Ctrl+Enter / Ctrl+⌫

Tab completions

Ghost-text completions from a fast model, debounced so they stay cheap. Toggle, snooze or disable per language from the status bar.

Tab accept · Alt+\ trigger

Terminal and commits

Ctrl+K in the terminal turns a sentence into a command (Run / Insert / Edit). The sparkle in Source Control writes a commit message from your staged diff.

Permissions you control

Shell commands stop at a Run / Skip / Always-allow card, exactly like Cursor's terminal approvals. Edits auto-apply or ask, per your setting. Plan mode shows a plan with Build / Reject.

Rules

Reads .cursor/rules/*.mdc (always, auto-attached, agent-requested, manual), .cursorrules, AGENTS.md and your User Rules; CLAUDE.md keeps working through Claude Code itself.

Fix in Chat

Lightbulb actions on diagnostics and selections: Fix in Chat, Add to Chat, Explain, Edit with Kursor. Terminal context menu: add selection, debug last command.

Omarchy-native on Linux

Follows your Omarchy theme automatically, registers in the launcher, optional SUPER+⇧+K binding and default-editor hookup. Plain Linux, macOS and Windows get the native integration too.

Inline edits that stay in your editor

Select code, press Ctrl+K, type what you want. The result is rendered as an in-place vertical diff: removed lines in red, new lines in green, with Accept and Reject lenses on every block. Nothing is written until you accept, and Ctrl+Z rejects everything.

Approve commands, review edits

When the agent wants to run something that isn't read-only, you get a card with the exact command, a one-line explanation and Run / Skip / Always allow. File edits show up as rows with +/− counts and Review, Undo and Keep buttons, and a review bar tracks the whole turn.

How it works

Kursor is two pieces: a rebranded VSCodium build and a VS Code extension. The extension never talks to Anthropic directly.

1 · Your Claude Code

Kursor finds the claude binary you already installed (mise, npm, Homebrew, the native installer) and spawns it unmodified with the Claude Agent SDK's streaming protocol. It signs in with its login; Kursor never reads, stores or forwards credentials.

2 · The editor

A stock VSCodium release, renamed to Kursor with its own icon, data folders and kursor:// scheme. Open VSX for extensions. The Kursor extension adds the chat pane, inline edits, completions and the Cursor keymap.

3 · Your machine, your plan

Every chat turn, inline edit and completion is a Claude Code call under your own Pro, Max, Team or Console account, at normal Claude Code rates. Nothing leaves your machine except what Claude Code itself sends.

Install

Two prerequisites on every platform: the Claude Code CLI installed and signed in (claude auth login), and Node.js 18+ to run the installer (not needed afterwards). Then pick your OS.

# from a release bundle (Kursor-linux-x64-<version>.tar.gz)
tar -xzf Kursor-linux-x64-*.tar.gz && cd Kursor-linux-x64-*/
bash install.sh                 # add --hypr-bind --default-editor on Omarchy

# or from source
git clone https://github.com/brucegrootgames/kursor.git && cd kursor
npm install && npm run package && bash product/install.sh
  1. Installs to ~/.local/opt/kursor, command kursor, a launcher entry and icons. No root.
  2. On Omarchy it also installs a theme hook so Kursor follows omarchy theme set.
  3. Launch with kursor or from your app launcher.
# from a release bundle (Kursor-darwin-arm64 or darwin-x64)
tar -xzf Kursor-darwin-arm64-*.tar.gz && cd Kursor-darwin-arm64-*/
bash install.sh                 # --system for /Applications

# or from source
git clone https://github.com/brucegrootgames/kursor.git && cd kursor
npm install && npm run package && bash product/install.sh
  1. Installs ~/Applications/Kursor.app and a kursor command in ~/.local/bin.
  2. The app is re-signed ad hoc after rebranding; the first launch may need right-click → Open.
  3. All shortcuts use ⌘ instead of Ctrl.
# from a release bundle (Kursor-win32-x64-<version>.zip), in PowerShell
Expand-Archive Kursor-win32-x64-*.zip -DestinationPath . ; cd Kursor-win32-x64-*
.\install.cmd                   # --desktop-shortcut, --system for Program Files

# or from source
git clone https://github.com/brucegrootgames/kursor.git ; cd kursor
npm install ; npm run package ; product\install.cmd
  1. Installs to %LOCALAPPDATA%\Programs\Kursor with a Start Menu shortcut, kursor on your user PATH and the kursor:// protocol.
  2. Open a new terminal afterwards for kursor to be found.

Re-running the installer upgrades in place and never overwrites your settings. uninstall.sh / uninstall.cmd remove everything (--purge also deletes settings).

FAQ

Do I need an Anthropic API key?

No. Kursor uses the Claude Code CLI on your machine, signed in with your own Claude account (Pro, Max, Team or Enterprise) or Console key. Sign in once with claude auth login.

What does it cost?

Kursor is free and MIT licensed. Chat turns, inline edits and Tab completions are regular Claude Code requests under your plan. Tab completions use a fast model and are debounced; turn them off from the status bar if you'd rather not spend quota on them.

Does Kursor send my code anywhere?

Only to Claude Code, which sends it to Anthropic as any Claude Code session would. The extension has no server, no telemetry and no analytics. Workspaces in Restricted Mode are never read until you trust them.

Can I keep using my VS Code extensions?

Yes. Kursor is VSCodium with the Open VSX gallery, so most extensions install normally. Your existing VS Code settings are not touched; Kursor keeps its own profile.

Is Tab as good as Cursor's?

Not yet. Cursor trains a dedicated model for next-edit prediction; Kursor asks a general fast model for a short continuation, with a ~1 s pause and a ~2.5 s round trip. It is useful for boilerplate, not for keystroke-level prediction.

How do updates work?

Every release ships bundles for all platforms. Download the new one and run its installer, or git pull and re-run product/install.sh / install.cmd: the app directory is replaced, your settings and chats stay.
